# Changelog

All notable changes to the AirCourier project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Initial project setup with Next.js 13
- Supabase database integration
- User authentication system (sign up/sign in)
- Beautiful homepage with hero section
- Package requests and trips display
- User profile management
- Responsive design with Tailwind CSS
- shadcn/ui component library integration

### Database Schema
- Created profiles table with user information
- Created package_requests table for delivery requests
- Created trips table for traveler offers
- Created matches table for connecting packages and trips
- Created messages table for user communication
- Created reviews table for user ratings
- Implemented Row Level Security (RLS) policies

### Features
- User registration with profile creation
- Email/password authentication
- Protected routes and data access
- Modern UI with gradient backgrounds
- Mobile-responsive design
- Trust and safety features display
